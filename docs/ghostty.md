Ghostty
===

[Ghostty](https://ghostty.org) is the only terminal. Its job here is small: render fast, look like the
rest of the setup, and hand everything about windows and sessions to [tmux](tmux.md).

What it is
---
- **A new window** attaches to the tmux session `main` (creating it if needed) when no other window shows
  it. Quitting Ghostty only detaches, so everything running in tmux keeps running and is there the next
  time you open it.
- **Further windows** (`cmd+n`) and the **quick terminal**, opened while a window already shows `main`, are
  plain zsh, for when you want a shell outside tmux.
- Each window decides when it opens, not just the first one Ghostty starts with: Ghostty restores the last
  session's windows, and a restored window you can't see must not keep tmux to itself. Close the tmux window
  and the next one you open attaches again.
- The tmux session is started through a login zsh, so the tmux server inherits the full `PATH` (Homebrew,
  fnm, `~/bin`). Without that, tmux popups and plugins started from Ghostty wouldn't find `fzf`, `zoxide` or
  `claude`.
- **Cmd shortcuts drive tmux**: Ghostty's Cmd shortcuts send the tmux prefix plus a key, so they behave like
  native shortcuts but act on tmux ([Keys](#keys)).
- **Look**: colours from `themes/base16`, generated by `change_theme` from the nvim colour scheme, so terminal
  and editor always match ([theme](theme.md)). Source Code Pro, with Nerd Font icons (eza, starship, nvim,
  tmux status bar) from Ghostty's built-in symbol fallback, made as tall as capital letters and digits
  (`adjust-icon-height`) and level with them (`adjust-font-baseline` moves the text up a pixel). Padding
  around the text, no cursor blink, the mouse hides while typing, and windows and their size are restored
  on restart.
- **Shell integration** is on (window titles, `sudo` keeps the terminfo), except the cursor shape, which zsh
  sets per vi mode. `ssh` to a host without Ghostty's terminfo installs it there or falls back to
  `xterm-256color`, so remote shells don't break. Inside tmux an alias sets `TERM=xterm-256color` for ssh
  instead (see [tmux](tmux.md)).

Adding a shortcut
---
1. Bind the action in `config/tmux/tmux.conf`.
2. In `config/ghostty/config`, have Ghostty send `\x01` (C-a) followed by that key.
3. Reload Ghostty with `cmd+shift+,`.

Keys
---
### Cmd shortcuts drive tmux

| Ghostty | tmux | Action |
|---|---|---|
| `cmd+t` | `C-a c` | new window |
| `cmd+d` / `cmd+shift+d` | `C-a \|` / `C-a -` | split right / down |
| `cmd+w` | `C-a x` | close pane (asks first) |
| `cmd+1`…`9` | `C-a 1`…`9` | go to window |
| `cmd+0` / `ctrl+0` | `C-a l` / `C-a ;` | back to the last window / pane, see [same key, every layer](design.md#same-key-every-layer) (`cmd+0` no longer resets the font size) |
| `cmd+[` / `cmd+]` | `C-a [` / `C-a ]` | previous / next window |
| `cmd+shift+[` / `cmd+shift+]` | – | nothing, see [Decisions](#decisions) |
| `cmd+shift+0` | `C-a S` | back to the last session |
| `cmd+shift+enter` | `C-a z` | zoom the pane |
| `cmd+k` | `C-a f` | session picker |
| `cmd+j` | `C-a w` | tree of all sessions and windows |
| `cmd+shift+j` | `C-a a` | the Claude Code agents only, most urgent first |
| `cmd+shift+space` | `C-a A` | the next Claude Code agent that needs you (1Password's Quick Access default: move that, see [setup](setup.md#a-new-mac)) |
| `cmd+f` | `C-a /` | search the scrollback |
| `cmd+r` / `cmd+shift+r` | `C-a ,` / `C-a $` | rename the window / session |

### Other keys

| Key | Action |
|---|---|
| `` ctrl+` `` (anywhere in macOS) | drop-down quick terminal; needs Accessibility access for Ghostty |
| `shift+enter` | newline without submitting (Claude Code, multi-line prompts) |
| `Option` | acts as Alt (Meta), for nvim, tmux and zsh bindings |
| `cmd+shift+,` | reload the config |
| `cmd+shift+w` | close a plain window |

Config
---
`config/ghostty/config`; all options with their docs: `ghostty +show-config --default --docs`. Colours are in
`config/ghostty/themes/base16`, generated (see [theme](theme.md)).

To look out for
---
- In a plain window the Cmd shortcuts type the escape sequence into the shell instead, so close plain windows
  with `cmd+shift+w`.
- `Option` is Alt, so typing `ø`, `ç`, … needs another input method.
- Don't edit `themes/base16` by hand: `change_theme` overwrites it.

Decisions
---
- **tmux's windows and splits, not Ghostty's tabs and splits**: sessions survive closing Ghostty.
- **No previous / next session on `cmd+shift+[` / `cmd+shift+]`**: too easy to mix up with previous / next
  window.
- **`cmd+0` is the last window, not the font-size reset**: it joins the "back to the last" family
  (`docs/design.md`, "Same key, every layer").
- **No patched Nerd Font**: Ghostty's symbol fallback draws the icons. At its defaults they stand out above
  and below the text next to them, hence `adjust-icon-height` and `adjust-font-baseline`.
