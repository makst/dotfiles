Ghostty
===

[Ghostty](https://ghostty.org) is the only terminal. Its job here is small: render fast, look like the
rest of the setup, and hand everything about windows and sessions to [tmux](tmux.md).

Config: `config/ghostty/config`. Reload with `cmd+shift+,`. All options with their docs:
`ghostty +show-config --default --docs`.

Windows: tmux and plain
---
- **A new window** attaches to the tmux session `main` (creating it if needed) when no other window shows
  it. Quitting Ghostty only detaches, so everything running in tmux keeps running and is there the next
  time you open it.
- **Further windows** (`cmd+n`) and the **quick terminal**, opened while a window already shows `main`, are
  plain zsh, for when you want a shell outside tmux.

Each window decides when it opens, not just the first one Ghostty starts with: Ghostty restores the last
session's windows, and a restored window you can't see must not keep tmux to itself. Close the tmux window
and the next one you open attaches again.

The tmux session is started through a login zsh, so the tmux server inherits the full `PATH` (Homebrew,
fnm, `~/bin`). Without that, tmux popups and plugins started from Ghostty wouldn't find `fzf`, `zoxide` or
`claude`.

Cmd shortcuts drive tmux
---
Ghostty doesn't use its own tabs and splits. Its Cmd shortcuts send the tmux prefix plus a key instead, so
they behave like native shortcuts but act on tmux:

| Ghostty | tmux | Action |
|---|---|---|
| `cmd+t` | `C-a c` | new window |
| `cmd+d` / `cmd+shift+d` | `C-a \|` / `C-a -` | split right / down |
| `cmd+w` | `C-a x` | close pane (asks first) |
| `cmd+1`…`9` | `C-a 1`…`9` | go to window |
| `cmd+0` / `ctrl+0` | `C-a l` / `C-a ;` | back to the last window / pane, see [same key, every layer](../README.md#same-key-every-layer) (`cmd+0` no longer resets the font size) |
| `cmd+[` / `cmd+]` | `C-a C-h` / `C-a C-l` | previous / next window |
| `cmd+shift+[` / `cmd+shift+]` | – | nothing: previous / next session was too easy to mix up with previous / next window |
| `cmd+shift+0` | `C-a S` | back to the last session |
| `cmd+shift+enter` | `C-a z` | zoom the pane |
| `cmd+k` | `C-a f` | session picker |
| `cmd+j` | `C-a w` | tree of all sessions and windows |
| `cmd+shift+j` | `C-a a` | the Claude Code agents only, most urgent first |
| `cmd+shift+space` | `C-a A` | the next Claude Code agent that needs you (1Password's Quick Access default: move that, see [setup](setup.md#a-new-mac)) |
| `cmd+f` | `C-a /` | search the scrollback |
| `cmd+r` / `cmd+shift+r` | `C-a ,` / `C-a $` | rename the window / session |

In a plain window these shortcuts type the escape sequence into the shell instead, so close plain windows
with `cmd+shift+w`. To add a shortcut: bind the action in `tmux.conf`, then have Ghostty send `\x01` (C-a)
followed by that key.

Other keys
---
| Key | Action |
|---|---|
| `` ctrl+` `` (anywhere in macOS) | drop-down quick terminal; needs Accessibility access for Ghostty |
| `shift+enter` | newline without submitting (Claude Code, multi-line prompts) |
| `Option` | acts as Alt (Meta), for nvim, tmux and zsh bindings. Typing `ø`, `ç`, … needs another input method |
| `cmd+shift+,` | reload the config |

Look
---
- **Colours** come from `themes/base16`, a file generated by `change_theme` from the nvim colour scheme, so
  terminal and editor always match. Don't edit it by hand, see [theme](theme.md).
- **Font**: Source Code Pro. Nerd Font icons (eza, starship, nvim, tmux status bar) come from Ghostty's
  built-in symbol fallback, so no patched font is needed. They're made as tall as capital letters and digits
  (`adjust-icon-height`) and level with them (`adjust-font-baseline` moves the text up a pixel); at Ghostty's
  defaults they stand out above and below the text next to them.
- Padding around the text, no cursor blink, the mouse hides while typing, and windows and their size are
  restored on restart.

Shell integration
---
Ghostty's zsh integration is on (window titles, `sudo` keeps the terminfo), with two adjustments:

- It doesn't change the cursor shape: zsh does that per vi mode.
- `ssh` to a host without Ghostty's terminfo installs it there or falls back to `xterm-256color`, so remote
  shells don't break. Inside tmux an alias sets `TERM=xterm-256color` for ssh instead (see [tmux](tmux.md)).
