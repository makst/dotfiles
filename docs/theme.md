Theme
===

One [base16](https://github.com/tinted-theming/home) colour scheme drives everything, so the editor,
terminal, prompt and tools always match. The current scheme is `base16-onedark`.

What it is
---
Only two things know the actual colours; everything else uses the terminal's 16 ANSI colours and follows
along:

| Uses the scheme directly | Uses the 16 terminal colours |
|---|---|
| nvim (`tinted-vim` colour schemes) | tmux (status bar, popups, menus, copy mode), starship prompt, fzf, bat, delta, glow (`mdv`) |
| Ghostty (`config/ghostty/themes/base16`, generated) | file colours in eza, fzf-tab and completion (vivid's `ansi` theme) |

Text is Source Code Pro. Icons in eza, starship, nvim and the tmux status bar are Nerd Font glyphs, which
Ghostty draws from its built-in symbol font.

Switching schemes
---
1. Run `change_theme` and pick a scheme (every base16 scheme tinted-vim ships, a few hundred): it opens ready
   to type, best match first; `jj` for `j`/`k` ([picker keys](tmux.md#picker-keys)). It writes the nvim colour
   scheme file and regenerates Ghostty's theme from the same colours, using the standard base16 → ANSI
   mapping.
2. Reload Ghostty (`cmd+shift+,`) and restart nvim.
3. Commit the two files to keep the scheme.

Config
---
| File | Contains |
|---|---|
| `config/nvim/lua/user/base16-vim.lua` | the scheme nvim loads, written by `change_theme` |
| `config/ghostty/themes/base16` | Ghostty's colours, generated by `change_theme` from the same scheme |
| `zsh/functions/theme.zsh` | `change_theme` |

To look out for
---
- `change_theme` needs nvim's plugins installed, because the scheme list comes from tinted-vim.
- Don't edit `themes/base16` by hand: the next `change_theme` overwrites it.

Decisions
---
- **ANSI colour names everywhere else, never hex**, so a new scheme reaches every tool through the terminal's
  16 colours without touching their config.
- **Plain Source Code Pro, not a patched Nerd Font**: Ghostty's built-in symbol font draws the icons.
